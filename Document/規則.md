# ディレクトリ・ファイル命名

|種類|命名規則（例）|役割|
|:----|:----|:----|
|ルート（URL）|blog-posts/|/blog-posts というURLに対応|
|動的ルート|[id]/|[slug] など。変数として扱われる|
|ルートグループ|(marketing)/|URLに影響を与えず、ファイルを整理する|
|プライベート|_components/|フォルダ全体をルーティングから除外する|
|予約済みファイル|page.tsx, layout.tsx|Next.jsが特定の役割として認識するファイル|


# コンポーネントの命名規則

- ファイル名: **UserCard.tsx（パスカルケース）**
- 関数名: **export default function UserCard() { ... }**
- URLになるフォルダ名： **kebab-case**

# 変数・関数の命名（TypeScript/JavaScript）

- 変数・関数: **camelCase（例: getUserData）**
- 定数: **UPPER_SNAKE_CASE（例: API_ENDPOINT）**
- 型（Type/Interface）: **PascalCase（例: UserProps）**
